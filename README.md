# Personal website

## Dev

```bash
# install dependencies
npm i

# run dev server
npx quartz build --serve
```

## Note

1. The `quartz.config.yaml` file is the configuration file for the Quartz theme. You can modify it to customize your website's appearance and behavior.
2. Dont modify the `content` folder directly. It is generated by Quartz Syncer Plugin of Obsidan. You can modify the content in your Obsidian vault and then use the Quartz Syncer Plugin to sync the changes to your website.
